# 固定入口取消默认并发限额

基于 2.5.8 r2；本次构建含红米 NMBM 110MiB BIN、S20L、S20P、京东云 RE-CP-03。尚未进行百台手机实机压测。

- 默认取消全局 128 条连接限额。
- 默认取消全局 64 条 UDP 转发流限额。
- 默认取消每个 UDP 会话 16 个目标限额。
- 可选 JSON 配置 data_max_connections、data_max_udp_flows、data_max_udp_flows_per_session；省略或 0 表示不设应用层数量限额，正数为管理员主动设限。改变全局限额需重启进程。
- 保留认证、目标绑定、出口切换隔离、UDP 空闲回收。
- 不改 DNS 查询并发机制，不改无线、网络或防火墙。

验证：go test ./... 通过。新增 256 条 TCP 同时保持并回显、80 条 UDP 流同时保持并回显、可选限额回收测试；现有切换隔离和认证测试通过。

这是程序功能测试，非 100 台手机实机容量证明。最终容量仍取决于系统文件描述符、内存、CPU、无线空口和出口带宽。
