设备分配（主 WiFi）

固定 IP + MAC

未绑定设备默认国内直连。代理节点故障时不会自动回落直连。手机请使用“固定/稳定的私有 WiFi 地址”。每台设备可独立选择 DNS。

DNS 设置

国内可选百度 / 阿里 / 腾讯；代理可选 Cloudflare / Google / Cisco OpenDNS / Quad9。代理 DNS 强制使用 DoH 并经对应代理出口，避免 DNS 直连泄漏。每台设备和每个附加 WiFi 还可以覆盖全局设置。

多 WiFi 管理

读取中…

默认固件只保留主 WiFi。需要时在这里新增：最多额外 14 个 5GHz + 8 个 2.4GHz。每个 WiFi 使用独立 172.16.x.0/24、独立 DHCP、AP 隔离和独立出口/DNS。

节点管理与机场订阅

手动批量导入

支持 SOCKS5 / SK5 / HTTP / HTTPS / VLESS / VMess / Trojan / SS / Hysteria2 / TUIC。每行一个，也支持常见的 host:port:user:pass 格式。失败时会显示具体行号和 dae 核心校验日志。

机场订阅

支持 HTTPS 订阅、Base64、Clash YAML、sing-box JSON；更新失败保留旧节点。
